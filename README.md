# 千纹万象 · 中国传统纹样生成式数字体验

> 真迹生纹，万象更新 —— 古人的纹样，今天的算法。

参赛作品：**2026 第十四届全国大学生数字媒体科技作品及创意竞赛（CMIT）**
赛道：指定命题 · 民族文化 创新表达

---

## 这是什么

**真迹 × 算法再创作**。把公有领域的中国传统纹样真迹数字化入库，由生成引擎把每幅真迹「圆窗化」，再按十一种传统构成法则重新织排——你选真迹、定骨架、配五色、调密度，算法便织出一张独一无二的纹样。

核心主张：**真迹是种子，算法是土壤**。

### 五大展厅

| 展厅 | 做什么 |
|---|---|
| **序 · 纹语** | 首页：真实素材轮播、纹样五千年时间轴、旅程总览 |
| **鉴 · 纹库** | 115 幅真迹图版，可搜索、可筛选、可对比 |
| **坊 · 纹生** | 工坊：11 种骨架 × 6 套配色 × 密度调节 × 对称镜像 × 纹色归一 |
| **彩 · 物化** | 四器物（瓷盘 / 梅瓶 / 折扇 / 织锦）实时投射 + AI 实物渲染 + 全视角视频 |
| **愿 · 纹签** | 写下心愿 → 生成祈福纹 → AI 解签 |

另有三个子页：纹样详情、纹样册（收藏与成就）、关于。

### 贯穿体验

- **一幅纹样的旅程**：五个展厅串成一条可走完的线（遇见 → 重塑 → 成器 → 寄愿 → 溯源）
- **纹博士**：悬浮对话导览，事实来自团队考据库 + 自研中文检索，大模型只负责组织语言
- **听 · 纹律**：11 种骨架实时译成五声音阶旋律，纯 Web Audio 程序合成
- **语音解说**：浏览器本地语音合成朗读，零网络零 Key
- **限时挑战**：三关难度递增（识谱 / 辨意 / 通纹），7 种题型由真实数据现算
- **纹样对比**：两幅真迹并排看谱系、寓意与同骨架织排对照
- **分享体系**：8 位纹样密码（可分享可复刻）+ 1080×1080 分享卡

## 快速运行

```bash
# 双击启动器（自动起本地服务 + 打开浏览器）
# 开发机上若存在 _dev\keys.local.js，启动器会自动投放、页面自动预填模型配置；
# 其他机器没有该文件，启动器与页面都走"未配置"的干净路径，在页面设置面板手填。
千纹万象\启动作品.bat
```

或手动：

```bash
cd 千纹万象
python _serve.py 8765      # 推荐：带 no-store 缓存头 + 模型代理
# 或 python -m http.server 8765
```

打开 http://localhost:8765/

**必须走 http://**——`file://` 下画布会被本地图片污染，PNG/SVG 导出与 AI 取图都会失败。

> `serve.ps1` 提供三层降级（Python → PowerShell HttpListener → 自实现 TcpListener），**评委机不需要 Python** 也能运行。

## 技术栈

**纯前端 · 零构建 · 零依赖 · 零 CDN**

| 层 | 实现 |
|---|---|
| 前端 | 原生 HTML + CSS + Vanilla JS（30 个文件，经典 `<script>` 标签，非 ES module） |
| 路由 | Hash 路由，8 个视图 |
| 渲染 | 原生 Canvas 2D；自制 Canvas2D 记录器导出 SVG（矢量构图 + 真迹位图去重内嵌） |
| 样式 | 单一 `style.css`（约 2600 行），约 40 个设计令牌；三主题（素 / 宣纸 / 墨夜） |
| 字体 | 思源宋体 Bold 子集（792 字形，OFL 可商用），仅用于标题 |
| 音频 | Web Audio API 程序合成（无采样素材） |
| 语音 | 浏览器 SpeechSynthesis（零网络零 Key） |
| 服务 | Python `http.server` 包装层（no-store 缓存头 + 模型代理）；PowerShell 三层降级 |
| 存储 | localStorage（收藏、主题、语言、模型配置、挑战成绩） |

### 模型接入（可插拔）

作品自带一个同源代理层（`_serve.py`），把模型请求转发到上游：

```
浏览器 → /api/llm/chat（大语言模型）  → magpie 本机网关 或 自定义 OpenAI 兼容接口
       → /api/media/relay（图像/视频） → 自填平台（地址 + Key + 两个模型名）
       → /api/media/check             → 连接校验（SSRF 校验 + TCP 连通性）
```

- **大语言模型**：支持本机 magpie 聚合网关（模型清单动态拉取）或任意 OpenAI 兼容接口
- **图像 / 视频模型**：用户提供平台地址、API Key、图像模型名、视频模型名即可接入
- **安全**：代理侧做完整 SSRF 校验（拒绝环回 / 内网 / 保留地址，含 DNS rebinding 与重定向逐跳复验）；Key 只存本机 localStorage，作品源码零凭据
- **降级**：无 Key / 断网 / 调用失败时自动降级（纹博士回落本地考据摘录、签文回落本地规则签文、图像视频展示预生成示例并明确标注）

## AI 使用披露

按竞赛指南要求如实披露：**织排构图、器物效果图、配色、动效、检索算法与知识库均为团队自研，无 AI 参与**。大模型只承担三类辅助角色：

| 环节 | 角色 | 说明 |
|---|---|---|
| 纹博士对话 / 签文 | 组织语言 / 解签 | 事实来自团队考据库 + 自研检索，回答附「资料依据」可逐条核对 |
| AI 实物渲染 | 真实感升级 | 以程序绘制的器物效果图为参考做图生图 |
| AI 全视角视频 | 器物展示 | 始终图生视频（以本次渲染图为参考），绝不静默降级为文生视频 |

**约束放在检索层，而非压在模型嘴上**——从机制上杜绝幻觉与「脱离语境的符号拼贴」。无 Key / 断网时全部自动降级，评委无需任何配置即可完整演示。

详见 `千纹万象/docs/人工智能工具使用情况说明.docx`。

- **字体**：思源宋体（Source Han Serif），SIL OFL 授权，可商用。
